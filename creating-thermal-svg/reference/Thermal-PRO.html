Letters
One path traced from the video frame, a Helvetica-style bold. 1.2 KB of path data.

        
Shadow
The shape's alpha blurred by 8 units, times the same #9d9d9d grey.

        
Stripe
486-unit period on a 4.4 s loop, moving up and to the right at 35°. The video's last two seconds play at half speed; set the loop to 8.8 s to match them.

        
Color
A 17-step table fitted to the frames: navy, cyan, peach, orange, red, pink, white.

        
Grain
Fractal noise mixed in at 0.14, close to the video's noise level.

      

      
The code on screen in the video is shortened. The path and tables are cut off, and the gradient and noise lines are simplified. This file is complete and runs as is in any modern browser.
